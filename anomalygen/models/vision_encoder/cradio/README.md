# cradio

C-RADIO vision-encoder backbones (RADIO ViT family) used as the feature extractor
for AnomalyGen.

## Source

This code is adapted from NVIDIA TAO PyTorch:

<https://github.com/NVIDIA-TAO/tao-pytorch/tree/main/nvidia_tao_pytorch/cv/backbone_v2>

The upstream directory is named `backbone_v2`; it is vendored here as `cradio` to
reflect that AnomalyGen only uses the C-RADIO backbone.
